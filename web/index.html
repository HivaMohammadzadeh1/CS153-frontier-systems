How Learning Memory OS works

1
Semantic retrieval — your question is embedded and matched against 20+ knowledge items from the curriculum using cosine similarity.
2
Heuristic scoring — each item is scored on relevance, recency, misconception coverage, prerequisite coverage, and reuse penalty.
3
Budget packing — items are greedily packed into a token budget (default 3000) to form the tutor's context window.
4
Claude tutor — the tutor responds using only the packed context, citing items by short ID, which the UI converts to numbered references.
Q
Quiz + diagnostics — generate a quiz question on the current topic, and if you score below 0.6, a diagnostic conversation begins to identify the misconception.
